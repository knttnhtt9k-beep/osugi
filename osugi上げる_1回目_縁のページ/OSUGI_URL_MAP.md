## 禁止

- ルートの `index.html` / `type.html` / `types-data.js` を、運命の人診断のファイルで上書きすること
- GitHubの「Add files via upload」で、Downloadsの診断フォルダをルートにそのまま上げること
- 新しい診断をルート直下に置くこと

新しい診断は、必ず新しいフォルダ（例: `unmei/`）か、新しいリポジトリに置く。
